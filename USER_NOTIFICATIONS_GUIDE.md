# 📢 User Notifications Guide

## Where Regular Users Will See Notifications

### 🔔 Access Notifications

Regular users (non-admins) can access notifications in **two ways**:

#### **Method 1: Bell Icon on Home Screen** (Quickest)
1. Open the FarmVet app
2. **Log in** with your account
3. Look at the **top-right corner** of the home screen
4. Tap the **🔔 Bell icon**
5. You'll see all notifications from admins

#### **Method 2: Using App Navigation Menu**
1. Open the FarmVet app
2. Log in
3. Open the **side menu** (hamburger menu)
4. Look for **"Notifications"** option
5. Tap it to view all notifications

---

## 📋 What Users Will See

### Notifications List
Each notification shows:
- ✅ **Title** - The subject/heading of the notification
- ✅ **Message** - Full content/details
- ✅ **Image** - If admin included a picture
- ✅ **Date** - When it was sent (e.g., "2h ago", "Yesterday")
- ✅ **Status** - Whether it's Active or Archived

### Features Available to Users
- 📖 **Read notifications** - View full details
- 🔄 **Pull to refresh** - Update the list manually
- 📸 **View images** - See pictures included with notifications
- 🕐 **See timestamps** - Know when each notification was sent
- 📊 **Count badge** - See total number of notifications

## 🔄 How Notifications Work

### Flow:
1. **Admin creates notification** → Sends via Admin Panel
2. **Saved to Firestore** → `notifications` collection
3. **User logs in** → Opens FarmVet app
4. **User taps bell icon** → Notifications appear instantly
5. **User can read** → View all notifications sent by admins

### Real-time Updates:
- Notifications are **instant** - No delay
- Users see **newest first** (latest notifications on top)
- Can **refresh manually** to get latest notifications

## ❓ FAQs

### Q: Where do I find notifications?
**A:** Tap the 🔔 bell icon on the top-right of your home screen.

**A:** Yes! Notifications appear instantly when admins send them.

### Q: Can I delete notifications?
**A:** Notifications stay in your history. You can refresh to load new ones.

**A:** Currently shown in-app only. Check the app regularly for updates.

### Q: Why don't I see notifications?
**A:**

- Restart the app

### Q: Can I search notifications?

### Q: How long are notifications kept?
**A:** Notifications stay in the app indefinitely. Admins can delete if needed.
